# 热点消息真假分辨（redianfenxi-Y-N）

一个用于核实热点消息真伪并辟谣的 Codex Skill。

## 功能

- 提取热点消息中的核心论断（主体、事件、时间、地点、数字、引语）
- 多源交叉查证：官方机构 → 权威媒体 → 事实核查平台 → 当事方官方账号 → 其他媒体
- 判定真伪等级：真实 / 虚假 / 部分属实 / 过时或已解决 / 无法证实
- 输出逐条核验分析、置信度说明，以及可直接转发的“辟谣后真实内容”

## 使用方法

在 Codex 中直接发送：

```text
真的假的：<热点消息>
```

或使用“帮我核实这条消息”“帮我分辨真假”“辟谣”等说法触发。
