# 查证指南

## 信源优先级

| 级别 | 信源 | 用途 |
|---|---|---|
| S1 | 官方机构与官方通报：政府、部委、卫健委、公安、应急管理、气象、铁路、市场监管等 | 结论的主要依据 |
| S2 | 权威媒体：新华社、人民日报、央视新闻、澎湃新闻、财新、南方周末等 | 交叉印证 |
| S3 | 事实核查平台：中国互联网联合辟谣平台、腾讯较真、澎湃明查、微博辟谣 | 快速定位已被辟谣的信息 |
| S4 | 当事方官方账号：涉事企业、机构、个人的认证账号与原始发布者 | 还原一手信息 |
| S5 | 其他媒体、自媒体、群聊截图 | 仅作线索，不作结论依据 |

## 常用权威平台（通过搜索直达最新页面）

- 中国互联网联合辟谣平台：www.piyao.org.cn
- 微博辟谣：weibo.com/piyao
- 腾讯较真：vp.fact.qq.com
- 澎湃「明查」栏目：thepaper.cn 内搜索「明查」
- 各地网信办辟谣频道、公安部网安局通报

## 搜索技巧

- 用原句加引号搜索，检查是否已被辟谣平台或权威媒体引用。
- 组合「主体 + 事件 + 时间」精确搜索。
- 使用「辟谣」「真相」「通报」「官方回应」等词检索。
- 对数字、日期、政策名称做单独精确搜索，核对数值与单位。
- 反向查证：查找官方是否有相关发布，查找图片或视频的原始出处。

## 常见造假模式

| 模式 | 识别要点 |
|---|---|
| 旧闻新炒 | 事件真实但发生在过去，被重新包装为「刚刚」「今天」；核对原始报道时间 |
| 张冠李戴 | 图片、视频或事件与文字描述不符；反向搜图、搜视频关键帧 |
| 断章取义 | 引用被截取、脱离上下文；查找原始讲话或文件全文 |
| AI 生成 | 图片视频由 AI 生成；检查手部、文字、光影细节，配合识图工具 |
| 数据失真 | 数字被夸大、单位或口径被篡改；回查原始统计来源 |
| 假冒官方 | 账号、公文或截图仿冒官方；核对认证标识与官网发布 |
| 情绪化标题 | 标题煽动、正文无出处；情绪强度本身是警惕信号 |

## 输出模板

### 脱敏要求（输出前必做）

- 移除或替换：真实姓名、用户名与账号 ID、头像、手机号、邮箱、住址、工作单位、聊天记录、个人主页链接。
- 截图证据一律转述，不直接贴出可能含个人信息的原始截图。
- 使用通用占位表述：「发布者」「爆料人」「网传信息」。
- 输出末尾注明「已对个人信息脱敏，可公开使用」。

### 分析内容

- 原始消息摘要
- 核心论断列表
- 逐条查证结果（结论、证据、信源链接）
- 判定结论：真实 / 虚假 / 部分属实 / 过时或已解决 / 无法证实，附置信度
- 存疑点与查证局限
- 脱敏说明

### 辟谣后的真实内容

- 正确事实（简洁陈述）
- 与原消息的差异（哪里错了、哪里被夸大）
- 依据与来源
- 可转发的干净版本
- 确认不含任何用户个人信息
